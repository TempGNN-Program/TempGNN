# Paper Figure Reference Provenance

`results/result.csv` contains the 668 source-labeled numeric records used by
`python3 -m scripts.reproduce_paper_figures`. The records are
an anonymized transcription of the accepted-paper plotting sources. They are
loaded by `tempgenn/result.py`.

The LF-normalized `results/result.csv` has SHA-256
`b92cafe211f9f001f097898b1aae59c3c132ed6e9956176394fd14c034b3d147`;
the same digest is recorded in `tempgenn/result.py` as `RESULT_CSV_SHA256`.

The reference figures and fresh measurements are deliberately separate:

- `results/paper_reproduction/`: deterministic regeneration of
  CSV/SVG files from `results/result.csv`. The directory is not
  pre-populated in the AE archive.
- `results/reviewer_u280_runs/<run-id>/`: rows freshly emitted by four distinct
  U280 xclbins, including board logs, checksums, power samples, and provenance.

The source workbooks and vector exports are not included because their file
metadata belongs to the non-anonymous author workspace. The anonymized Python
records retain cell/geometry locators, source hashes, extraction class, and
uncertainty notes so every generated value has an auditable origin.

## Transcription Notes

- Fig.10 and Fig.13 use exact workbook cells. Their model blocks follow the
  published axis order `JODIE`, `TGN`, `TGAT`, `APAN`. Two labels in a
  neighboring workbook block are swapped; the numeric block order is confirmed
  by the published vector figure.
- Fig.11, Fig.12, and Fig.14 did not have a separate numeric table in the
  recovered author directory. Their values are digitized from vector geometry,
  not synthesized from prose averages.
- The explicit Fig.11 AVG bar digitizes to `7.7889` for TempGNN/MATG, while the
  paper narrative reports `7.6x`. This package preserves the plotted source and
  records the discrepancy instead of forcing either value.
- Explicit AVG cells/bars are retained as source rows. They are not silently
  replaced by an average of rounded per-point values.

No value in the code records is generated by interpolation from a reported
mean or range. The former `_scaled_grid` construction and its synthetic
motivation data were removed.
